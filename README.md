# Requirements
- Python 3.12
- Cuda 12.1
- GPU with at least 16GB of memory
- 32GB of RAM
- conda

# Installation
1. Clone the repository
git clone git@github.com:thisisandy/ml-hw.git
git checkout hw3
2. Install the requirements using conda
cd ml-hw
conda env create -f environment.yml
conda activate ml-hw
3. Install the requirements using pip
pip install -r requirements.txt
3. Run the code
Code are in the hw3 folder. Run the code respectively.
For example, to run the code against digit dataset against svm, run the following command:
```
python hw3/*.py
```

Relavant output figures and files will be saved in the hw3/result folder.

For overleaf report, please visit the following link:
https://www.overleaf.com/read/bdwhymrtqsbs#be7db7
